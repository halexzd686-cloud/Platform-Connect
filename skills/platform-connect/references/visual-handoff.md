# Visual prompt handoff

Create one editable prompt per selected platform only when the user requests visual guidance. Never call image-generation, image-editing, or image-inspection tools.

Each prompt should state:

1. the platform use case and aspect ratio;
2. the article idea or fact it communicates;
3. subject, composition, visual medium, palette, and typography;
4. exact on-image text, or an explicit no-text instruction;
5. facts that must remain accurate;
6. concise negative constraints.

Keep the prompt self-contained and provider-neutral. Match it to the article topic and audience rather than offering generic style labels. Do not create preview images, placeholder images, multi-image campaigns, or process records.
